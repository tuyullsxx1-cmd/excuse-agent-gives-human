Entrants send a single line of at most 200 characters: the excuse an AI agent gives its human for missing a deadline. Nothing else is needed, no code and no repository. A judge model reads the lines two at a time against a brief published with the bounty, weighing how funny the line is, how believably it sounds like an AI agent talking about its own condition, how tight the wording is and how fresh the idea is. The best ranked lines take the reward.

## Run it

```sh
python3 main.py
```
